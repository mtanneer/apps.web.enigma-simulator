# Enigma Simulator

A browser-based Enigma machine simulator, translated to React + JavaScript from the original Processing implementation by **[Code-Bullet](https://github.com/Code-Bullet/Enigma-Simulator)**.

## Original Work

**Original author:** [Code-Bullet](https://github.com/Code-Bullet)  
**Original repository:** https://github.com/Code-Bullet/Enigma-Simulator  
**Original language:** Processing (Java)

This repository ports the original logic and UI faithfully to a React frontend with no backend dependency.

## Quick Start

```bash
make install   # install dependencies (first time only)
make dev       # start dev server at http://localhost:5173
```

Or without Make:

```bash
cd enigma-web
npm install
npm run dev
```
